Política de Privacidade

Última atualização: 18 de setembro de 2026

A Abner Transportes, relacionada à empresa Abner Jose Duarte da Silva, CNPJ 64.947.541/0001-04, respeita a privacidade das pessoas que entram em contato conosco e apresenta nesta página como os dados pessoais podem ser tratados.

1. Quais dados podem ser coletados

Podemos receber dados fornecidos voluntariamente pelo visitante, como nome, telefone, e-mail, empresa, informações relacionadas à carga e dados necessários para solicitar uma cotação ou atendimento.

2. Para que utilizamos os dados

Os dados podem ser utilizados para responder solicitações, preparar cotações, prestar atendimento, executar serviços de transporte, cumprir obrigações legais e melhorar nossos canais de comunicação.

3. Compartilhamento

Os dados somente poderão ser compartilhados quando necessário para a execução do serviço, cumprimento de obrigação legal ou exercício regular de direitos, observadas as regras aplicáveis.

4. Segurança

Adotamos medidas razoáveis de segurança para proteger os dados contra acesso não autorizado, perda, alteração ou divulgação indevida.

5. Direitos do titular

Nos termos da legislação aplicável, o titular poderá solicitar informações sobre o tratamento de seus dados e exercer os direitos previstos na legislação de proteção de dados, observadas as hipóteses legais.

6. Exclusão de dados

Solicitações relacionadas à exclusão de dados podem ser feitas pela página Instruções de Exclusão de Dados.

7. Contato

Para assuntos relacionados a privacidade, utilize os canais oficiais informados pela Abner Transportes.

Observação: esta página é uma descrição informativa das práticas do site e deve ser revisada pelo responsável jurídico da empresa antes de ser adotada como documento definitivo.
